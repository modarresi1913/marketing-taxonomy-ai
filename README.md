## What Is This?

Marketing Taxonomy AI (MTA) is the **first comprehensive open-source classification** of marketing types. Think of it as the periodic table for marketing — a structured, searchable, community-driven reference that maps the entire marketing landscape.

Unlike scattered blog posts and textbook chapters, MTA provides:

- **228 distinct marketing types** organized across 4 hierarchical levels
- **3 evolution tiers**: Core (established), Extended (specialized), Emerging (2025-2026 frontier)
- **Real-world case studies** with brand examples and measurable outcomes
- **Status tracking**: Verified, Merged, Removed, Renamed — showing how the field evolves
- **Interactive web explorer** for browsing, searching, and visualizing the taxonomy
- **Community-driven**: Anyone can add new types or examples via pull request

## Quick Examples

### Core: Viral Marketing
> **Volkswagen — "The Force"**
> Super Bowl ad featuring a boy in a Darth Vader costume trying to use the Force on household objects. Shared tens of millions of times, becoming one of the most shared commercials ever.

### Core: Word-of-Mouth Marketing
> **Dropbox — Referral Program**
> Offered 500MB extra storage to both parties. Grew from 100K to 4M users in 15 months — a 3,900% increase driven almost entirely by word of mouth.

### Core: Guerrilla Marketing
> **Coca-Cola — "Happiness Machine"**
> Special vending machine dispensed free Cokes, flowers, and pizza. Video went viral with millions of views at a fraction of traditional ad costs.

### Emerging: Agentic Marketing
> **Salesforce Agentforce**
> Deploys autonomous AI agents that independently handle campaign planning, audience segmentation, and content personalization 24/7 with minimal human oversight.

### Emerging: Livestream Commerce
> **Li Jiaqi on Taobao Live**
> Sold 15,000 lipsticks in 5 minutes and generated $1.9B in pre-sales during a single 2021 Singles' Day session.

### Run it locally

```bash
# Clone the repo
git clone https://github.com/modarresi1913/marketing-taxonomy-ai.git
cd marketing-taxonomy-ai

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the interactive explorer.

## Data Structure

The source of truth is `data/marketing-types.json` — a simple, human-readable JSON file that anyone can edit and submit via PR.

```json
{
  "version": "1.0.0",
  "stats": { "total": 228, "withExamples": 8 },
  "marketingTypes": [
    {
      "id": 1,
      "name": "Account-Based Marketing (ABM)",
      "category": "B2B Strategic",
      "tier": "core",
      "status": "Verified",
      "examples": [
        {
          "brand": "GumGum → T-Mobile",
          "description": "Custom comic book casting T-Mobile's CEO as a superhero..."
        }
      ]
    }
  ]
}
```
